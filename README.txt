VIETPATH – BẢN CODE HOÀN CHỈNH MỞ RỘNG

Giữ cấu trúc giao diện VietPath/ClassDojo-style trước đó, đồng thời bổ sung:
- 4 vai trò: Giáo viên, Gia sư, Phụ huynh, Học sinh
- Quản lý lớp và học sinh
- Kho học liệu: upload file + Drive + YouTube + Canva + link ngoài
- Bài tập và giao bài
- Luyện tập tương tác cơ bản
- Học sinh nộp bài + file/ảnh tên file + giáo viên chấm/nhận xét
- Điểm danh
- Điểm thưởng và huy hiệu
- Công cụ random/chia nhóm/timer
- Gia sư: buổi học, học phí, đã thu, công nợ, nhận xét
- Lịch
- Nhận xét và tin nhắn
- Thông báo
- Thống kê
- Excel import/export + JSON backup
- PWA cài trên điện thoại

CHẠY:
1. Giải nén.
2. Mở index.html bằng Chrome/Edge để thử.
3. Để PWA/service worker hoạt động ổn định, chạy qua localhost hoặc HTTPS.

LƯU Ý:
Đây vẫn là bản prototype front-end. Dữ liệu hiện lưu localStorage trên từng thiết bị.
Đăng nhập đang mô phỏng. Muốn tài khoản thật, đồng bộ nhiều máy, push notification và cloud file cần Firebase/Supabase/backend.
